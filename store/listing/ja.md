# Chrome Web Store listing: FillHub (日本語)

**Name:** FillHub

**Summary (132 characters max):**
15言語で、現実的で一貫した架空データを使ってウェブフォームを入力します。安全モード、元に戻す機能。データ収集なし。

## Description

FillHubは、現実的で一貫性のある架空データでウェブフォームを入力します。開発者とテスト担当者は、テスト値を手入力することなく、また実在する人物の情報を使うことなく、会員登録、決済、データ入力の流れを検証できます。

主な機能

- 15言語と15か国のプロファイル。氏名、住所、電話番号、会社名、識別番号は各国の形式に従います。
- 一貫した人物データ。1回の入力で1人分の人物を生成します。そのため、名、姓、メールアドレス、「メールアドレス（確認）」フィールド、ユーザー名、電話番号が互いに一致します。
- スマートなフィールド検出。FillHubはラベル、フィールド名、オートコンプリートのヒント、入力タイプを組み合わせて各フィールドを判定します。他の言語のラベルも認識します。たとえば、トルコ語で「Cep telefonu」（携帯電話）と書かれたフィールドには電話番号が、「Soyadınız」（あなたの姓）と書かれたフィールドには姓が入力されます。
- PII Safeモード（既定で有効）。個人を特定する情報には、テスト用と明らかにわかる値を使用します。example.comのメールアドレス、プレースホルダーの電話番号、実際の利用を想定していないテスト用の識別番号です。
- アイデンティティ・プロフィール。入力のたびに新しいランダムな人物を使うか、固定の人物を使うかを選べます。プロフィールでは名、姓、メールアドレス、電話番号、パスワードを固定できるため、毎回同じテストアカウントで入力できます。
- カスタムルール。標準の検出で認識されないフィールドがある場合は、CSSセレクタをデータ種別に割り当てます。ルールは設定ページで編集します。
- 同意のチェックボックス（利用規約、プライバシーポリシー、トルコの個人データ保護法に基づくKVKKの同意）はオンになります。マーケティング用のチェックボックスはオフのままです。
- テキストフィールドには、その国の言語の例文が入ります。例文はフィールドの最大文字数に合わせて短縮されます。
- ファイル入力フィールドには、受け付けるファイル形式に合った小さなファイルが生成されて添付されます。
- 自動送信（任意、既定ではオフ）は、入力したフォームの実際の送信ボタンをクリックします。キャンセルや削除などの破壊的なボタンはクリックしません。特定のサイトを自動送信の対象外にできます。
- CAPTCHAはクリックも解決もしません。表示されているCAPTCHAは枠で示されるので、ご自身で完了してください。この場合、フォームは自動送信されません。
- カオスモードは、ファズテスト向けに通常とは異なる値をフィールドに入力します。
- 元に戻す機能は、フォームを直前の入力より前の状態に戻します。
- 設定はローカルのJSONファイルにバックアップできます。不具合報告用の診断レポートには件数と基本的な設定が含まれますが、氏名、フィールドの値、サイトのアドレスは含まれません。
- 同一オリジンのiframe内でも動作し、JavaScriptフレームワークと値を同期します。異なるオリジンのiframeはactiveTabの許可の範囲外のため、入力されません。

使い方

1. フォームのあるページを開きます。
2. Ctrl+Shift+F（macOSではCommand+Shift+F）を押すか、ツールバーのFillHubアイコンをクリックします。フォームがすぐに入力されます。
3. Ctrl+Shift+U（macOSではCommand+Shift+U）を押すと、入力を元に戻せます。
4. Ctrl+Shift+Y（macOSではCommand+Shift+Y）を押すと、カオスモードでファズテスト向けの通常とは異なる値を入力します。

ショートカットは chrome://extensions/shortcuts で変更できます。1つのフィールドだけを入力するには、そのフィールドを右クリックして「このフィールドを入力」を選びます。

プライバシー

FillHubはデータを収集せず、ネットワークリクエストも行いません。設定はお使いのブラウザ内にのみ保存されます。拡張機能は作者にも第三者にも何も送信しません。プライバシーポリシー: https://github.com/kilicberkay/FillHub/blob/main/PRIVACY.md

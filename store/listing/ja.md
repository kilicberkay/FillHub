# Chrome Web Store listing: FillHub (日本語)

**Name:** FillHub

**Summary (132 characters max):**
15言語で、現実的で一貫した架空データを使ってウェブフォームを入力します。安全モード、元に戻す機能。データ収集なし。

## Description

FillHubは、現実的で一貫性のある架空データでウェブフォームを入力します。開発者とテスト担当者は、テスト値を手入力したり実在の人の情報を使ったりせずに、会員登録・決済・データ入力の流れを検証できます。

主な機能

- 15言語と15か国のプロファイル。氏名、住所、電話番号、会社名、識別番号は各国の形式に従って生成されます。
- 一貫した人物像。1回の入力で1人分のデータを生成するため、姓名、メールアドレス、「メールアドレス（確認）」欄、ユーザー名、電話番号が互いに一致します。
- スマートなフィールド検出。ラベル、名前、オートコンプリートのヒント、入力タイプを組み合わせて判定するため、「Cep telefonu」や「Soyadınız」といったラベルの欄にも正しい値が入ります。
- PII Safeモード（既定で有効）。個人を特定する情報には明らかなテスト用の値を使用します。example.comのメールアドレス、プレースホルダーの電話番号、実際の利用を想定しないテスト用の識別番号です。
- アイデンティティプロファイル。入力のたびに新しいランダムな人物を使うか、固定の人物を使うかを選べます。プロファイルで名、姓、メールアドレス、電話番号、パスワードを固定でき、固定のテストアカウントとして使えます。
- カスタムルール。標準の検出で認識されない欄があれば、CSSセレクタをデータ種別に割り当てられます。ルールは設定ページで編集します。
- 同意のチェックボックス（利用規約、プライバシー、KVKK）はオンになり、マーケティング用のチェックボックスはオフのままです。
- テキスト欄には、国の言語による例文が入ります。欄の最大長に合わせて切り詰められます。
- ファイル入力欄には、受け付ける形式に合った小さなファイルが生成されて添付されます。
- 任意の自動送信（既定ではオフ）は、入力したフォームの実際の送信ボタンをクリックします。キャンセルや削除などの破壊的なボタンは決してクリックされず、サイトを除外することもできます。
- キャプチャは決してクリックも解決もされません。表示されているキャプチャは枠で示されるので、ご自身で完了してください。フォームは自動送信されません。
- 異常な値でファズ型のテストを行うためのカオスモード。
- 元に戻す機能で、直前の入力の前の状態にフォームを戻します。
- 設定のローカルJSONファイルへのバックアップと、件数のみを含む診断レポート。
- 同一オリジンのiframe内でも動作し、ページの言語でラベルを読み取り、JavaScriptフレームワークとも値を同期します。異なるオリジンのiframeはactiveTabの許可外のため、変更されません。

使い方

1. フォームのあるページを開きます。
2. Ctrl+Shift+F（macOSではCommand+Shift+F）を押すか、ツールバーのFillHubアイコンをクリックします。フォームがすぐに入力されます。
3. Ctrl+Shift+Uで元に戻します。
4. Ctrl+Shift+Yでカオスモード（ファズテスト向けの異常な値）になります。

ショートカットは chrome://extensions/shortcuts で変更できます。1つの欄を右クリックして「この欄を入力」を選ぶと、その欄だけを入力できます。

プライバシー

FillHubはデータを収集しません。設定はお使いのブラウザに保存されます。拡張機能は作者にも第三者にも何も送信しません。プライバシーポリシー: https://github.com/kilicberkay/FillHub/blob/main/PRIVACY.md

# Chrome Web Store listing: FillHub (Русский)

**Name:** FillHub

**Summary (132 characters max):**
Заполняет веб-формы реалистичными и согласованными тестовыми данными на 15 языках. Безопасный режим, отмена, без сбора данных.

## Description

FillHub заполняет веб-формы реалистичными и согласованными тестовыми данными. Разработчики и тестировщики могут проверять сценарии регистрации, оформления заказа и ввода данных без ручного ввода тестовых значений и без использования реальных данных людей.

Основные возможности

- 15 языков и 15 профилей стран. Имена, адреса, номера телефонов, названия компаний и идентификационные номера соответствуют формату каждой страны.
- Согласованные данные человека. Одно заполнение создаёт одного человека. Поэтому имя, фамилия, адрес электронной почты, поле «Повторите адрес электронной почты», имя пользователя и номер телефона соответствуют друг другу.
- Интеллектуальное распознавание полей. Чтобы определить назначение поля, FillHub учитывает подпись, имя поля, подсказки автозаполнения и тип поля. Подписи на других языках тоже распознаются. Например, турецкое поле с подписью «Cep telefonu» (мобильный телефон) получает номер телефона, а поле с подписью «Soyadınız» (ваша фамилия) получает фамилию.
- Режим PII Safe (включён по умолчанию). Для личных идентификаторов используются явно тестовые значения: адреса электронной почты на example.com, номера-заглушки и тестовые идентификационные номера, которые не предназначены для реального использования.
- Профили личности. Используйте нового случайного человека при каждом заполнении или постоянного человека. Профиль может закрепить имя, фамилию, адрес электронной почты, номер телефона и пароль, чтобы при каждом заполнении использовалась одна и та же тестовая учётная запись.
- Пользовательские правила. Сопоставьте CSS-селектор с типом данных, если встроенное распознавание не определяет поле. Правила редактируются на странице настроек.
- Флажки согласия (условия использования, политика конфиденциальности и согласие KVKK по турецкому закону о защите персональных данных) отмечаются. Маркетинговые флажки остаются неотмеченными.
- Текстовые поля получают примеры предложений на языке страны, сокращённые до максимальной длины поля.
- Поля выбора файла получают небольшой сгенерированный файл допустимого типа.
- Автоматическая отправка (необязательная, по умолчанию выключена) нажимает настоящую кнопку отправки заполненной формы. Деструктивные кнопки, например «Отмена» или «Удалить», никогда не нажимаются. Отдельные сайты можно исключить из автоматической отправки.
- Капча никогда не нажимается и не решается. Видимая капча выделяется рамкой, чтобы вы прошли её самостоятельно. В этом случае форма не отправляется автоматически.
- Режим хаоса заполняет поля необычными значениями для фаззинг-тестирования.
- Функция отмены возвращает форму в состояние, которое было до последнего заполнения.
- Настройки можно сохранить в локальный JSON-файл. Диагностический отчёт для сообщений об ошибках содержит счётчики и основные настройки, но не содержит имён, значений полей и адресов сайтов.
- Работает во фреймах того же источника и синхронизирует значения с JavaScript-фреймворками. Фреймы других источников находятся вне разрешения activeTab и не заполняются.

Как пользоваться

1. Откройте страницу с формой.
2. Нажмите Ctrl+Shift+F (на macOS Command+Shift+F) или щёлкните значок FillHub на панели инструментов. Форма заполнится сразу.
3. Нажмите Ctrl+Shift+U (на macOS Command+Shift+U), чтобы отменить заполнение.
4. Нажмите Ctrl+Shift+Y (на macOS Command+Shift+Y), чтобы заполнить форму в режиме хаоса необычными значениями для фаззинг-тестирования.

Сочетания клавиш можно изменить на странице chrome://extensions/shortcuts. Чтобы заполнить только одно поле, щёлкните по нему правой кнопкой мыши и выберите «Заполнить это поле».

Конфиденциальность

FillHub не собирает данные и не выполняет сетевых запросов. Настройки хранятся только в вашем браузере. Расширение ничего не отправляет автору или третьим лицам. Политика конфиденциальности: https://github.com/kilicberkay/FillHub/blob/main/PRIVACY.md

Ответственное использование

FillHub предназначен для тестирования и разработки. Сгенерированные идентификационные номера могут проходить общедоступные проверки контрольных сумм. Не используйте сгенерированные данные для реальных заявок, покупок или подтверждения личности.

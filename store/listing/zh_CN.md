# Chrome Web Store listing: FillHub (简体中文)

**Name:** FillHub

**Summary (132 characters max):**
以15种语言用真实且一致的虚构数据填写网页表单。安全模式、撤销功能，且不收集任何数据。

## Description

FillHub 使用真实且一致的虚构数据填写网页表单，让开发者和测试人员无需手动输入测试值，也无需使用真实个人信息，即可测试注册、结账和数据录入流程。

亮点

- 15 种语言和 15 个国家配置。姓名、地址、电话号码、公司名称和身份号码都遵循各国的格式。
- 人物信息保持一致。每次填写只生成一个人，因此名字、姓氏、电子邮件、“再次输入电子邮件”字段、用户名和电话号码彼此相符。
- 智能字段识别。结合标签、名称、自动完成提示和输入类型进行判断，因此标签为“Cep telefonu”或“Soyadınız”的字段也能获得正确的值。
- PII Safe 模式（默认开启）。个人标识符使用明显的测试值：example.com 电子邮件地址、占位电话号码以及绝不用于实际用途的测试身份号码。
- 身份配置文件。每次填写使用新的随机人物，或保持使用固定人物。配置文件可以固定名字、姓氏、电子邮件、电话和密码，因此可以保存一个固定的测试账户。
- 自定义规则。当内置识别遗漏某个字段时，可以将 CSS 选择器映射到数据类型。规则在设置页面中编辑。
- 同意类复选框（条款、隐私、KVKK）会被勾选；营销类复选框保持未勾选。
- 文本字段会填入该国语言的示例句子，并按字段的最大长度截断。
- 文件输入框会收到一个符合可接受类型的小型生成文件。
- 可选的自动提交（默认关闭）会点击已填写表单的真实提交按钮。取消、删除等破坏性按钮从不会被点击，并且可以排除某些网站。
- 验证码从不会被点击或破解。可见的验证码会被标出，由您自行完成，表单也不会自动提交。
- 混沌模式，用于使用异常值进行模糊测试。
- 撤销可将表单恢复到上一次填写之前的状态。
- 设置可备份为本地 JSON 文件，诊断报告仅包含计数。
- 可在同源 iframe 中工作，按页面自身的语言读取标签，并与 JavaScript 框架保持值同步。跨源 iframe 不在 activeTab 授权范围内，不会被修改。

使用方法

1. 打开一个包含表单的页面。
2. 按 Ctrl+Shift+F（macOS 上为 Command+Shift+F），或点击工具栏中的 FillHub 图标。表单会立即填写。
3. 按 Ctrl+Shift+U 撤销。
4. 按 Ctrl+Shift+Y 进入混沌模式（用于模糊测试的异常值）。

快捷键可在 chrome://extensions/shortcuts 中更改。右键点击单个字段并选择“填写此字段”，即可只填写该字段。

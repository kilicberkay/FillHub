# Chrome Web Store listing: FillHub (简体中文)

**Name:** FillHub

**Summary (132 characters max):**
以15种语言用真实且一致的虚构数据填写网页表单。安全模式、撤销功能，且不收集任何数据。

## Description

FillHub 使用真实且一致的虚构数据填写网页表单。开发者和测试人员无需手动输入测试值，也无需使用真实个人信息，即可测试注册、结账和数据录入流程。

亮点

- 15 种语言和 15 个国家配置。姓名、地址、电话号码、公司名称和身份号码均遵循各国的格式。
- 人物数据保持一致。每次填写只生成一个人物，因此名字、姓氏、电子邮件、“再次输入电子邮件”字段、用户名和电话号码彼此相符。
- 智能字段识别。FillHub 结合标签、字段名称、自动完成提示和输入类型来识别每个字段。其他语言的标签同样可以识别。例如，标签为“Cep telefonu”（土耳其语，意为“手机”）的字段会填入电话号码，标签为“Soyadınız”（土耳其语，意为“您的姓氏”）的字段会填入姓氏。
- PII Safe 模式（默认开启）。个人标识信息使用明显的测试值：example.com 电子邮件地址、占位电话号码，以及不用于实际用途的测试身份号码。
- 身份配置。每次填写可使用新的随机人物，也可使用固定人物。身份配置可以固定名字、姓氏、电子邮件、电话号码和密码，从而在每次填写时使用同一个测试账户。
- 自定义规则。当内置识别无法识别某个字段时，可将 CSS 选择器映射到数据类型。规则在设置页面中编辑。
- 同意类复选框（使用条款、隐私政策，以及土耳其数据保护法要求的 KVKK 同意）会被勾选。营销类复选框保持未勾选。
- 文本字段会填入该国语言的示例句子，并按字段的最大长度截短。
- 文件输入框会收到一个符合可接受文件类型的小型生成文件。
- 自动提交（可选，默认关闭）会点击已填写表单的真实提交按钮。“取消”“删除”等破坏性按钮绝不会被点击。可将特定网站排除在自动提交之外。
- FillHub 绝不会点击或破解验证码。可见的验证码会被框出，由您自行完成。在这种情况下，表单不会自动提交。
- 混沌模式会用异常值填写字段，用于模糊测试。
- 撤销功能可将表单恢复到上一次填写之前的状态。
- 设置可以备份到本地 JSON 文件。用于报告问题的诊断报告包含计数和基本设置，但不包含姓名、字段值或网站地址。
- 可在同源 iframe 中工作，并与 JavaScript 框架保持值同步。跨源 iframe 不在 activeTab 权限范围内，不会被填写。

使用方法

1. 打开一个包含表单的页面。
2. 按 Ctrl+Shift+F（macOS 上为 Command+Shift+F），或点击工具栏中的 FillHub 图标。表单会立即填写。
3. 按 Ctrl+Shift+U（macOS 上为 Command+Shift+U）撤销填写。
4. 按 Ctrl+Shift+Y（macOS 上为 Command+Shift+Y）以混沌模式填写表单，使用适合模糊测试的异常值。

快捷键可在 chrome://extensions/shortcuts 中更改。如需只填写一个字段，请右键点击该字段并选择“填写此字段”。
